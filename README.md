# Repositorio de estudio AZ-204 en español

Este repositorio centraliza y organiza material de estudio para la certificación **Microsoft Azure AZ-204: Developing Solutions for Microsoft Azure**. Aquí se recopilan recursos de teoría, guías, preguntas y respuestas, y laboratorios prácticos provenientes de distintos autores y fuentes, con el objetivo de tener todo en un solo lugar y en español.

La traducción, curaduría y creación de guías y PDFs fue realizada por **Max Carrion**. El crédito por el contenido original en inglés se mantiene para sus autores y creadores respectivos.

## Propósito del repositorio

El objetivo de este espacio es ayudar a estudiar AZ-204 de una forma más ordenada y accesible. En vez de tener el material disperso en varios sitios, aquí se agrupan los recursos más útiles para:

- estudiar la teoría principal del examen;
- practicar con preguntas y respuestas;
- seguir laboratorios paso a paso;
- revisar guías resumidas y material de apoyo;
- consultar archivos traducidos al español.

- [instructions/](Microsoft-Azure-AZ-204-Laboratorios_Practicos/instructions): laboratorios organizados por tema.

- Azure Key Vault y soluciones seguras;
- autenticación con Microsoft Entra ID;
- escenarios de .NET, PowerShell y despliegue en Azure.

Algunos subdirectorios incluyen ejemplos de código y proyectos listos para usar, por ejemplo:

- [instructions/azure-app-auth/authapp](Microsoft-Azure-AZ-204-Laboratorios_Practicos/instructions/azure-app-auth/authapp): ejemplo de aplicación .NET con autenticación.

## Cómo usar el material

Una forma práctica de aprovechar el repositorio es la siguiente:

1. Empezar por la [guía de estudio](Apuntes_y_Guias/AZ-204_Guia_Estudio_Completa_ES_Traducida.md) para entender los temas del examen.
2. Revisar las [preguntas y respuestas de práctica](Microsoft-Azure-AZ-204-Desarrollo-de-soluciones-para-examenes-de-practica-de-Microsoft-Azure-preguntas-y-respuestas/README.es.md) para reforzar conocimientos.
3. Seguir los [laboratorios prácticos](Microsoft-Azure-AZ-204-Laboratorios_Practicos/index.md) para llevar la teoría a la práctica.
4. Consultar los PDFs y apuntes resumidos cuando necesites repasar rápido.
